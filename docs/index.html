От APK до просмотра

Телевизор и DLNA-сервер должны быть в одной локальной сети.

Уже была старая версия? Как перенести историю.

  1. Скачайте APK

    Возьмите последнюю версию и перенесите файл на телевизор через USB или по сети.

  2. Откройте файл на телевизоре

    Запустите APK в файловом менеджере и подтвердите установку. Android может попросить разрешение для этого источника.

  3. Выберите диск

    Откройте «Диск ТВ», выберите найденный сервер и запустите видео. О новых версиях приложение сообщит само.
