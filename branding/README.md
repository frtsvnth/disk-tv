# Оформление Диск ТВ

Логотип: синяя киноплёнка вокруг экрана, название «Диск ТВ», тёмный синий градиент.
Изображения созданы встроенным генератором изображений и сохранены в PNG.

`DiskTV-logo.png` содержит отступы для круглой маски Android. Адаптивная иконка
дополнительно использует отступ 12%. `DiskTV-banner.png` — горизонтальный баннер TV.

Основной запрос: curved perforated blue film ribbon wrapping a screen window with a blue horizon; midnight navy background; exact Cyrillic wordmark «Диск ТВ»; no letter-shaped monogram.
